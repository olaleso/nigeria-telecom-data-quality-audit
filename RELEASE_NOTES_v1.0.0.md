# v1.0.0 — MDPI Reproducibility Release

This release contains the reproducibility package accompanying the manuscript:

**Auditing Public Telecommunications Data Quality in Nigeria: A Reproducible ISO/IEC 25012 Assessment and DAMA-DMBOK-Informed Governance Framework**

## Included

- Final V3 Python audit script
- Pinned Python dependency specification
- Final V3 machine-readable audit outputs
- Audit metadata
- Citation metadata
- Zenodo metadata

## Study scope

The release supports the analysis of seven National Bureau of Statistics telecommunications workbooks covering Q2 2024 to Q4 2025.
